# Changelog

## v0.1.0 — Initial version

- Adds a thin cross-contract consistency closure for existing target designs.
- Defines `ALIGNED`, `BLOCKED`, and `NO_CONTRACT_CHANGE` result states.
- Routes new design decisions to the required external `grill-with-docs` companion.
- Adds conditional references for project initialization, incomplete-policy repair, and readable contract output.
- Preserves project rendering overrides and requires direct authority for representation changes.
- Separates internal result classification from concise, single-language human presentation.
- Adds five bounded behavioral fixtures covering aligned, blocked, no-change, localized, and incomplete-adapter outcomes.
